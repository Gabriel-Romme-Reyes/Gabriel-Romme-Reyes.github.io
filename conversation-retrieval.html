APPLIED AI · RETRIEVAL & EVALUATION

Context-Aware Reply Recommender

I built retrieval and evaluation tooling to find relevant examples in conversation history and make the selected context easier to inspect.

What I built

Hybrid retrieval

Combined lexical and embedding-based signals to surface candidate conversation examples.

Inspectable ranking

Exposed ranking information and context so reviewers can assess the returned precedents.

Self-match exclusion

Implemented exclusion of the current relationship while retaining valid examples from other relationships, with synthetic regression cases.

Result

In progress · retrieval and evaluation lab

This project is in progress. Current work focuses on combining lexical and embedding retrieval, excluding misleading self-matches, exposing ranking evidence, and building a repeatable human-review workflow before any live use.

  • Python
  • Embeddings
  • Lexical search
  • Rank fusion
  • Evaluation
Why this work mattered

Can you find a useful precedent without retrieving the same conversation?

Finding similar text is only part of retrieval. Reviewers need to see why an example appeared, and misleading self-matches need to be excluded before the results are useful for evaluation.
